# Spec Management Skill

Esta habilidade define como interagir com os requisitos do projeto.

1. **Fonte da Verdade:** O arquivo `SPEC.md` na raiz é absoluto. Se o código discordar da Spec, o código está errado.
2. **Atualização:** Antes de qualquer código novo, verifique se existe um RF (Requisito Funcional) correspondente.
3. **Planejamento:** Use o arquivo `PLAN.md` (crie se não existir) para rastrear o progresso.
