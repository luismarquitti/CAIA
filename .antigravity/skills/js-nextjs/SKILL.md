# Next.js Skill

Use estes padrões ao gerar código frontend:

1. **Framework:** Next.js 14 (App Router).
2. **Estilo:** Tailwind CSS.
3. **Componentes:** Prefira Server Components por padrão. Use `'use client'` apenas quando necessário (interatividade).
4. **Testes:** Use Jest + React Testing Library.
